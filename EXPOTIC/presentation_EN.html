Context

The problem

Combinatorial optimization lies behind delivery routes, factory production, and resource allocation: decisions where trying every combination is impossible.

🧨
They are NP-hard
Exact methods don't scale: computation time explodes with problem size.
🧭
Metaheuristics are used
Tabu Search (TS) obtains high-quality solutions in practical time.
🕳️
The gap
Studies compare TS against other algorithms, but no one quantifies how much each internal mechanism of TS contributes using public code.
Research question How much does each Tabu Search mechanism —dynamic list, frequency memory, diversification— improve the solution when applied to five heterogeneous problems?

Theoretical framework

How does Tabu Search work?

It explores neighboring solutions and stores recent moves in a tabu list: going back is forbidden → it escapes local optima.

🚀

constructive heuristic
→
🔍

✅

→
📝
Update memory
tabu list + incumbent
⟳
Extensions The search can be enriched with aspiration criteria, restarts, frequency memory, and adaptive penalization — exactly what this project quantifies.
Proposal

Three progressive levels

Each level contains the previous one → the contribution of each mechanism can be isolated.

Level 1
Basic TS
  • Fixed-size tabu list
  • Simple neighborhood (2-opt, swap, flip)
  • Stop by iterations
Level 2 · + adds
Intermediate TS
  • Dynamic tabu list
  • Aspiration criterion
  • Soft restart on no improvement
Level 3 · + adds
Advanced TS
  • Frequency memory
  • Adaptive penalization
  • Informed diversification (double-bridge in TSP)

Discussion

Which mechanism contributes most?

1

Frequency memory + penalization

Greatest global impact
Decisive in CVRP: the simple operator gets trapped in deep local optima.
2

Informed perturbation (double-bridge)

Critical in TSP
Escapes attraction basins without being recaptured by the tabu list.
3

Dynamic tabu list

Modest contribution
6.50% → 4.00%; long-term mechanisms add an extra 0.60 pp.
4

Quality initial heuristic

The starting point matters
In Flowshop the three levels barely improve on the NEH solution.
